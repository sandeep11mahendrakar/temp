# SITE_LIBRARY (S0)

Curated site registry for vision runs. Unknown fields are `null`
(never invented); credentials are ENV NAMES only (never values).

## Files

- `vision/src/siteLibrary.js` — lib (validate + refuse policy).
- `sites/cli.js` — node CLI: `add|get|list|link-run|validate`.
- `sites/<id>.json` — one file per site (written by `add` only).
- `sites/sites.index.json` — GENERATED by `add`/`validate --write-index`.
- `sites/runs/<run-id>.json` — run links (`mcp.perceive`/`mcp.act`
  slots, null until an MCP run attaches). `sites/runs.log` audits every
  link attempt, refusals included.

## Schema

`id` (`^[a-z0-9-]+$`), `url` (http/s), `access`
(`open|credentialed|third_party`), `cred_env` (null or
`{username,password}` ENV NAMES), `truth_ref` (repo-relative path that
must exist, or null), `source` (repo file evidencing the URL), `notes`.

## Validate (4 checks)

required-fields, access-enum, truth_ref-exists, no-secrets
(`AIza[35]` / `password=` / `key=`).

## Refuse rule

`access=third_party` launches are REFUSED unless `--permitted` (logged
either way). runAuto.js wiring is S1-PARKED (awaiting user); S0 keeps
runAuto.js untouched — the policy lives in `linkRun`/`canLaunch`.
